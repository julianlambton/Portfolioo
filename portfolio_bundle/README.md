## 🚀 How to Deploy

### Option 1: GitHub Pages (Recommended)
```bash
git init
git add .
git commit -m "Initial portfolio commit for Julian Casilimas Beltran"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo-name>.git
git push -u origin main
```
Then navigate to **Settings > Pages** on GitHub, select `main` branch, and click **Save**.

### Option 2: Netlify Drop / Vercel
Simply drag and drop the folder containing `index.html`, `style.css`, and `script.js` directly into [Netlify Drop](https://app.netlify.com/drop) or [Vercel](https://vercel.com).
